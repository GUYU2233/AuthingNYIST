# macOS GUI 验收

在 macOS 13+ 的 Intel / Apple Silicon 机器上分别执行。Linux 交叉编译仅验证 Go 核心，不能替代以下验收。

## 构建与首次启动

1. 执行 `bash scripts/build-macos.sh`，检查架构、签名与 DMG 验证全部成功。
2. 将对应架构 App 拖入 Applications，验证首次启动、系统安全提示与菜单栏图标。
3. 使用测试系统账号或备份原配置，避免覆盖日常认证凭据。

## 窗口与菜单栏

- 首次打开可设置账号；启动读取状态期间窗口仍响应。
- 网络选项包含自动检测、nyist-tec、nyist-stu；保存后重开保持一致。
- 菜单栏可打开窗口、查看状态、连接、停止保活、登出和检查更新。
- 操作期间相应按钮禁用；状态失败显示未知或失败，不显示为已确认离线。
- 关闭窗口可继续驻留菜单栏；重新打开不会创建第二个认证进程。
- 登出默认取消，确认后才中断连接；退出应用停止所属保活进程。
- 检查更新显示结果，发布页面在浏览器打开。

## 配置与生命周期

- GUI 与 CLI 使用同一配置；保存保留未展示的配置字段。
- 启动不自动认证，不因状态检查改写账号。
- 已有其他账号在线时，连接和登出仍被共享核心拒绝。
- 配置损坏时保存被禁用；修复后重启可正常加载。
- 长时间请求超时后恢复操作，退出清理所属子进程。
- 登录项设置仅打开系统设置；用户自行添加或移除 App，并实际注销登录后验证。

## 发布边界

Developer ID 签名与 Apple 公证需要发布者证书及凭据；当前构建为 ad-hoc 签名，不能宣称已公证。记录系统版本、CPU、测试结果和真实校园网认证结果后再发布给普通用户。
