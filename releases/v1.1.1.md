# v1.1.1 · 连接与网络状态修复

NYIST Connect 是南阳理工学院校园网助手，支持 nyist-tec / nyist-stu 一键认证。Windows 提供图形界面、托盘后台和开机启动，Linux 提供命令行及服务部署。

## 本次更新
- 修复未认证时因接口返回数字类型的 `ecode` 而出现 `invalid portal response`、无法继续登录的问题，并兼容纯文本离线响应。
- 按学校官方页面的注销方式，使用在线会话的完整账号和 IP 发送注销请求；增加注销后的状态确认，避免仍在线却显示注销成功。
- 改进“检查状态”：区分本机未连接网络、当前 Wi-Fi 与所选校园网络不一致、校园网未认证及认证服务器不可达。检测过程不会自动连接或注销。
- 增加离线认证、注销确认及网络状态诊断的回归测试，保留其他在线账号的会话保护。

## 下载与使用
- Windows：下载 `nyist-connect.exe`。更新前请从托盘菜单彻底退出旧程序，再启动新版；仅关闭窗口可能仍会保留后台进程。
- Linux：根据架构下载 `nyist-connect-linux-amd64` 或 `nyist-connect-linux-arm64`，部署方法见 `NYIST-CONNECT.md`。
- 另附传统命令行客户端、说明文档及 SHA-256 校验文件。

说明：本次修复通过自动化回归测试；未通过主动断开当前工作网络进行完整实网断线重连验收。无物理网络连接时仍需先连接校园 Wi-Fi 或有线网络，才能访问认证服务。
