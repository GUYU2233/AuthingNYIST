# v1.1.0 · 更紧凑的校园网助手

NYIST Connect 为南阳理工学院校园网提供一键认证，支持 nyist-tec / nyist-stu。Windows 提供图形界面、托盘后台与开机启动，Linux 提供命令行及服务部署方式。

## 本次更新
- 缩小 Windows 默认窗口并收紧控件间距，操作更紧凑。
- 加入贴底、等比例缩放的校园校徽背景，原图纯黑区域改为透明，背景位于控件底层。
- 改进 Windows GUI 自动化冒烟测试的原生控件识别。
- 为 GitLab 安全扫描的 Runner 基础设施故障增加自动重试。

## 下载与使用
- Windows 用户下载 `nyist-connect.exe`，选择网络并填写账号密码即可连接。
- Linux 用户根据架构选择 `nyist-connect-linux-amd64` 或 `nyist-connect-linux-arm64`，部署方法见 `NYIST-CONNECT.md`。
- `auth-nyist.*` 为传统命令行客户端；附件提供文档与 SHA-256 校验文件。

Windows 密码使用 DPAPI 加密保存；退出程序不会主动注销校园网。感谢原项目 Palvef/AuthingNYIST。
